# AR Interior Design Assistant

A web-based interior design assistant that combines camera-based room visualization with virtual furniture placement and smart design recommendations.

## Features

- Camera-based room preview
- Virtual furniture placement
- Sofa, table, chair, lamp, bed and plant options
- Drag and reposition furniture
- Rotate furniture
- Increase and decrease furniture size
- Delete placed furniture
- Room type selection
- Modern, Minimal and Classic design styles
- Budget-based recommendations
- Smart furniture and colour suggestions
- Save design using browser local storage
- Responsive web interface

## Project Workflow

1. Select the room type.
2. Select the preferred design style.
3. Select the budget.
4. Start the camera.
5. Preview the room.
6. Add virtual furniture.
7. Move, resize or rotate furniture.
8. View smart design recommendations.
9. Save the completed design.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser Camera API
- Local Storage
- Rule-based Recommendation Engine
